# DOCX Anonymizer

Расширение для Chrome и Edge, которое **локально, без единого сетевого запроса** находит в договорах `.docx`
персональные и коммерческие данные и заменяет их плейсхолдерами (`[ФИО_1]`, `ООО «[КОМПАНИЯ_1]»`, `[ИНН_1]`)
до того, как файл уйдёт в ChatGPT, Claude или другой LLM-сервис. Форматирование документа сохраняется.
Таблица «плейсхолдер → значение» остаётся у вас; ответ ИИ можно вставить в расширение и получить текст с реальными значениями.

> Статус: в разработке (первая версия). Рамки — `docs/mvp-scope.md`, полное ТЗ — `docs/spec-full.md`.

## Установка (из исходников)

1. Node.js 22+. `npm install`
2. `npm run build` — появится каталог `dist/`.
3. Chrome → `chrome://extensions` → включить «Режим разработчика».
4. «Загрузить распакованное расширение» → выбрать `dist/`.
5. Перехват загрузки выключен по умолчанию — включается в меню расширения.

## Разработка

| Команда | Что делает |
|---|---|
| `npm test` | модульные и интеграционные тесты (Vitest) |
| `npm run e2e` | сборка + e2e в Chromium с расширением (Playwright, headless) |
| `npm run lint` | ESLint |
| `npm run build` / `build:dev` | сборка в `dist/` (dev — с sourcemaps) |
| `npm run sample` | образец договора `tests/fixtures/sample-contract.docx` (вымышленные стороны) |

Архитектура и контракты модулей — `docs/contracts.md`, план работ — `docs/tasks.md`.

## Приватность

- Ни одного сетевого запроса: CSP `connect-src 'self'`, линтер запрещает `fetch`/`XMLHttpRequest`/`WebSocket`.
- Содержимое документа и маппинг живут только в памяти и не записываются в хранилище браузера.
