# Концепция версии 0.3: PDF с текстовым слоем

Версия 0.2 закрыла NER, разрешения по запросу, склонение и CI (`docs/concept-0.2.md`). Самый частый формат договора после DOCX — PDF, и сейчас расширение пропускает его в чат нетронутым. Версия 0.3 добавляет перехват PDF с текстовым слоем. Сканы без текстового слоя — не в этой версии: они отклоняются с понятной подсказкой.

## Почему не «PDF → PDF»

В PDF текст хранится как глифы с координатами, шрифты встроены частично — только те буквы, что есть в документе. Подставить `[ФИО_1]` в такой шрифт нельзя, а «настоящая» редактура потоков содержимого хрупка и легко оставляет текст под закраской. Для разбора договора ИИ нужен текст, а не вёрстка. Поэтому результат анонимизации PDF — **текстовый файл с плейсхолдерами** (`имя.anon.md`, по выбору `.txt`), который уходит в чат вместо PDF. Карта замен и восстановление ответа — те же, что для DOCX.

## Цели

| № | Цель | Что получает пользователь |
|---|------|---------------------------|
| Ц1 | PDF-договор перехватывается так же, как DOCX | Прикладываешь `.pdf` в чат — панель, список находок, в чат уходит `имя.anon.md` |
| Ц2 | Текст извлекается читаемо: абзацы, заголовки, таблицы, без колонтитулов | ИИ видит структуру договора, а не кашу из строк |
| Ц3 | Тот же уровень анонимизации, что для DOCX | Все детекторы, словари, модель NER и исключения работают на тексте PDF без изменений |
| Ц4 | Честные границы | Скан, защищённый паролем или пустой PDF отклоняются с подсказкой; смешанный документ обрабатывается с предупреждением |
| Ц5 | Ни одного сетевого запроса и ничего нового в хранилище | pdf.js и его данные — в пакете расширения; документ — только в памяти |

## Как это устроено

1. **Перехват.** `src/content/files.js` узнаёт `.pdf` (расширение и MIME `application/pdf`); настройка `pdfMode: 'markdown' | 'text' | 'off'` (по умолчанию `markdown`). При `off` PDF проходит как раньше.
2. **Извлечение.** В worker offscreen-документа работает pdf.js (Apache 2.0, вендорится в `vendor/pdfjs/` вместе с CMaps и стандартными шрифтами, сеть отключена). Из каждой страницы берутся текстовые элементы с координатами и размером шрифта; модуль `src/core/pdf/layout.js` собирает из них строки, абзацы, заголовки (по размеру шрифта), списки, таблицы (по выравниванию колонок) и отбрасывает повторяющиеся на страницах колонтитулы и номера страниц.
3. **Модель документа.** Текст PDF становится обычным `DocModel` с потоками-абзацами (`src/core/docx/model.js` получает второй конструктор `fromText`), поэтому `analyze()` и база знаний сторон работают без изменений. Применение замен — в тексте; результат сериализуется в Markdown (заголовки `#`, таблицы `|`, разрывы страниц — горизонтальной чертой) или в plain text.
4. **Панель и предпросмотр.** Та же панель; вкладка «Текст» показывает извлечённый текст с подсветкой; кнопка «Скачать результат» отдаёт `.anon.md`.
5. **Проверки на входе.** Нет текстового слоя (на странице меньше 20 символов букв) — отказ с подсказкой «похоже, это скан»; пароль — отказ; размер — тот же лимит `maxFileSizeMB`; смешанный документ (часть страниц без текста) — обработка с предупреждением «страницы N, M не содержат текста».
6. **Восстановление.** Без изменений: ответ ИИ с плейсхолдерами восстанавливается из карты сессии или `.mapping.json`.

## Что не делаем в 0.3

- Сканы и фотографии: OCR, закраска пикселей, детекция печатей. Это отдельная версия и кандидат на платную.
- «PDF → PDF» с сохранением вёрстки.
- Формулы, вложения и формы PDF (AcroForm): текст полей форм извлекается, если он в текстовом слое; иначе предупреждение.
- Публикация в Chrome Web Store — отдельное решение владельца; разрешения и манифест к ней уже готовы.

## Риски

- **Качество извлечения.** PDF, собранные разными генераторами (Word, LibreOffice, 1С, сканер с OCR-слоем), по-разному хранят пробелы и порядок элементов. Фикстуры из Chromium покрывают один генератор; критерий К3 измеряет паритет, но на «диких» PDF возможны склеенные слова. Митигация: эвристика пробелов по расстоянию между глифами, проверка на PDF из Word и LibreOffice вручную перед релизом (ручной чек-лист в README).
- **Размер pdf.js.** Полный набор CMaps велик; берём только те, что нужны для кириллицы и латиницы, и проверяем критерием К8.
- **Ожидания пользователя.** Кто-то ждёт PDF на выходе. Подсказка в панели объясняет, почему в чат уходит текст, и предлагает скачать `.anon.md`.
- **Колонтитулы.** Эвристика «повторяется на ≥ 3 страницах в одной зоне» может принять за колонтитул повторяющийся заголовок раздела; критерий К4 проверяет на фикстурах, в панели текст можно просмотреть до отправки.

## Оценка объёма

Один рабочий пакет WP10 (`docs/tasks.md`): извлечение и разметка — 2 дня агентной работы, перехват и панель — 0,5 дня, фикстуры и тесты — 1 день, документация — 0,5 дня. Без новых моделей и без обучения. Две волны: ядро и фикстуры параллельно с перехватом и UI; затем ревью, документация, финальная проверка критериев.
