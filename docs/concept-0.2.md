# Концепция версии 0.2

Версия 0.1.0 закрыла MVP: перехват файла в чате, локальная анонимизация по правилам и базе знаний сторон, обратная замена, воспроизводимый архив. Версия 0.2 закрывает пять пробелов, найденных при разборе проекта. Этот документ фиксирует цели и измеримые критерии, по которым в конце проверяется результат. Рабочие пакеты — в `docs/tasks.md` (WP6–WP9).

## Цели

| № | Цель | Что получает пользователь |
|---|------|---------------------------|
| Ц1 | Имена людей находятся в любом месте договора, не только рядом с метками | Меньше утечек ФИО третьих лиц в ИИ-сервис |
| Ц2 | ML-модель работает без единого сетевого запроса из расширения и без раздувания репозитория | Пакет модели скачивается с GitHub Releases, импортируется в настройках, хранится в браузере (OPFS) |
| Ц3 | Расширение не требует доступа ко всем сайтам | Доступ выдаётся по сайтам, которые пользователь включил; при установке нет предупреждений о доступе ко всем данным |
| Ц4 | Восстановленный текст читается по-русски | ФИО подставляется в нужном падеже, когда падеж определим по контексту; каждая склонённая подстановка подсвечена |
| Ц5 | Репозиторий выглядит как сопровождаемый продукт | Настоящая версия в манифесте, CI, ТЗ и контракты в согласии с кодом |

## Три ступени NER

1. **Словари и морфология** (WP7). Словари имён и фамилий с лицензиями, совместимыми с MIT, плюс уже существующая морфология. Правило «два признака из трёх»: имя из словаря в любом падеже, отчество по суффиксу, фамилия по словарю или суффиксу. Работает всегда, не требует модели.
2. **Пакет модели** (WP8). Формат zip-пакета с манифестом и хешами, импорт через настройки, хранение в OPFS, проверка целостности, удаление. Расширение не делает сетевых запросов: пакет скачивает пользователь.
3. **Локальная ONNX-модель** (WP9). `onnxruntime-web` на WASM в worker offscreen-документа, собственный WordPiece-токенизатор, модель на базе `cointegrated/rubert-tiny2`, дообученная на WikiANN ru+en, int8.

## Что не делаем в 0.2

- Встроенную модель Chrome (Prompt API / Gemini Nano).
- Публикацию в Chrome Web Store.
- WebGPU-ускорение: только WASM SIMD в одну нить; WebGPU — после замеров.
- IndexedDB вместо OPFS: только если OPFS окажется недоступен в worker offscreen-документа.

## Отклонения от ТЗ 0.1

- Модель **не входит** в пакет расширения (ТЗ §5.2 предполагало `models/` внутри). Она распространяется отдельным пакетом через GitHub Releases и импортируется пользователем. Причина: репозиторий публичный, модели в git не место; сетевых запросов из расширения по-прежнему ноль.
- FR-37 (восстановление в именительном падеже) заменяется склонением по контексту с подсветкой.
- Разрешения: вместо `host_permissions: <all_urls>` — `optional_host_permissions` и динамическая регистрация content script.
